Mod Manager

Windows app

Turn mods on and off without touching folders. Run KoboldKare Mod Manager.exe in the game folder.

  • Tick or untick a mod and Save. Ticking a mod also ticks the mods it needs.
  • Shows what each mod needs, what needs it, its config file and whether it loaded last time.
  • Warns about missing dependencies, old versions, duplicate IDs and errors from the last run.
  • Add Mod... (or drag and drop) installs a .dll or .zip, including Thunderstore layouts.
  • Save and Play starts the game through Steam. Untick Load mods to play without any.

ModKit

Framework

The base the other mods build on. You need it for every mod here, and modders can build on it too.

  • The shared F8 mod panel: one tab per mod, with sliders and toggles that save automatically.
  • Chat commands with autocomplete. /mods lists every mod's commands and panel tabs.
  • Map-load and per-frame events that keep working across map changes.
  • A start-up self-check that names any game code a mod needs but the game stripped out.

NPC AI

Gameplay

NPC kobolds stop standing around. They wander the map, take breaks, and pair up with each other.

  • NPCs roam to random spots and idle for a while between walks.
  • Now and then two NPCs find each other and head to an animation station, or pair up right where they stand.
  • Tune wander distance, idle and pairing times, and how often they pair, in the F8 panel.
  • /npc-ai on, off or status. Only the host runs it.

For proper path-finding, copy UnityEngine.AIModule.dll from a Unity 2021.3.45f2 install into BepInEx\unstripped_corlib. Without it, NPCs walk straight toward where they're going.

UI Theme

Looks

Recolour the whole game interface. Pick a theme, import one, or make your own with a live preview.

  • Choose a theme in Options > Graphics > UI Theme, the F8 panel, or /theme.
  • Create theme opens a colour editor with a live preview. Your themes keep the game's frame shapes and can be edited later.
  • Import themes from a .zip or a folder. Themes can set fonts and images too.
  • Comes with the Night Sky sample theme.

Voice Chat

Multiplayer

Proximity voice chat. Voices come from each player's kobold and fade with distance.

  • Hold V to talk, or switch to toggle or open mic.
  • Voices behind walls sound muffled, and pick up the map's reverb like other game sounds.
  • The bottom-left corner shows who's talking. Mute anyone with /voice mute <name>.
  • Test it alone: /voice block drops a cube that plays your mic back in 3D.

Everyone who wants to talk or listen needs the mod. It uses Steam voice, so start the game through Steam.

Movie Block

New · early

A floating video screen in the game world. Browse e621 or rule34.xxx by tag and watch videos with 3D sound.

  • /movieblock e621 or /movieblock r34 puts the screen in front of you, turned to face you.
  • F7 switches between using the screen and playing. Esc also takes you back.
  • Tag search with autocomplete, sort orders, a thumbnail grid, seek, loop and volume.
  • Click a video's tags to add them to your search, or exclude them. Only you see the screen.

Needs UnityEngine.VideoModule.dll from a Unity 2021.3.45f2 install in BepInEx\unstripped_corlib. rule34.xxx also needs a free API key (/movieblock r34key). Content involving minors is always filtered out.

Install in a minute

Works with the Steam version of KoboldKare on Windows.

Download

Get KoboldKare-ModLoader.zip from the Releases page.

Unzip into the game

Close the game. Unzip into the KoboldKare folder (Steam: right-click the game, Manage > Browse local files) and say yes to replacing files.

Pick and play

Run KoboldKare Mod Manager.exe, tick the mods you want, and click Save and Play.

Already have BepInEx? Grab KoboldKare-ModManager.zip and just the mod zips you want, then unzip them into the game folder or use Add Mod... in the Mod Manager. Unzipping a newer version over an old one is safe, and your settings in BepInEx\config are kept.

For modders

Every mod here is open source and built on ModKit. Make your own in a few lines.

// A chat command and an F8 panel tab with ModKit
[BepInPlugin("me.hello", "Hello", "1.0.0")]
[BepInDependency(ModKit.Guid)]
public class HelloPlugin : BaseUnityPlugin {
    void Awake() {
        ModCommands.Register("/hello", "Say hello",
            ctx => ctx.Reply("Hello " + ctx.Caller.name));

        ModPanel.AddPage("Hello", "ico_star", page => {
            page.Header("Settings");
            page.Toggle("Enabled", enabled);
        });
    }
}
  • Start a mod: new-mod.ps1 -Name MyMod copies the example mod into mods/MyMod.
  • Build: dotnet build mods/MyMod -c Release installs it into the game. While the game runs, add -p:Deploy=false and run deploy.ps1 later.
  • Safe by default: mods compile against the game's own stripped DLLs, so anything the game removed fails at build time, not in-game.
  • The README covers the ModKit API and this game's gotchas.
